# Spider R&D — DevOps Induction 2026
## Basic Task: `vault_sweep`

---

### The Situation

A developer pushed an unreviewed code at 2 AM on December 12th. The Spider monorepo is now considered **compromised**. Suspicious scripts, leaked credentials, and unknown processes have been reported.

You've been brought in from the Devops Team. Your job is to **investigate the environment, identify every threat, and write a bash script that automates the entire audit**.

---

### Prerequisites

- Docker installed on your machine → [Get Docker](https://docs.docker.com/get-docker/)
- Git
- SSH client (built into Linux/Mac; use Git Bash or WSL on Windows)

---

### Getting Started

```bash
# Clone this repo
git clone https://github.com/Lavanyaa-1204/spider-inductions-2026
cd spider-inductions-2026

# Build and start your env
bash setup.sh

ssh spider@localhost -p 2222
# Password: webslinger2026
```

You'll land inside a live Linux environment. Start exploring.

---

### Your Task

Write a bash script called `vault_sweep.sh` that audits the environment and automates everything you find manually.

Full task spec is in the task document shared with you.

Save your script at `/home/spider/vault_sweep.sh` inside the container.

---

### Submitting

When you're done, run this **on your host machine** (not inside the container):

```bash
bash export.sh
```

This copies your deliverables into `./my-submission/`. Push that folder to your own GitHub repo and submit the link.

Your submission repo should contain:
```
├── vault_sweep.sh
├── watchdog.sh          (bonus)
├── vault_sweep.log      (generated by running your script)
├── .env.sanitized       (generated by running your script)
└── REPORT.md
```
